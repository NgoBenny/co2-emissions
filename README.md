# CO2 Emissions

A Python desktop application for exploring U.S. state CO₂ emissions from 1970–2020. It imports the included CSV with pandas, reshapes yearly columns into records, and stores the data in SQLite. Users select a state in a Tkinter interface to query its history and display a Matplotlib trend chart.

Separate classes handle data storage, query processing, the interface, and plotting, demonstrating a complete path from tabular data to interactive visualization.
